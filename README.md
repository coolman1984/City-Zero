# مدينة الصفر

نموذج أولي قابل للعب للعبة بناء وإدارة مدينة، يعمل بتقنيات الويب ويُرسم لحظيًا من بيانات المحاكاة بدل الاعتماد على شاشات ثابتة.

## المزايا الحالية

- محاكاة حتمية للمال والمياه والطاقة والسكان والرضا والتلوث.
- مبانٍ قابلة للبناء والترقية.
- نهار وليل وطقس وسيارات متحركة.
- أزمة مياه متسلسلة وقرارات ذات نتائج.
- سياسات وشبكة علاقات بين أنظمة المدينة.
- كاميرا تدعم اللمس والسحب والتكبير.
- حفظ محلي مع نسخ احتياطية.
- واجهة متجاوبة للهاتف والكمبيوتر.

## التشغيل

يتطلب Node.js 22.13 أو أحدث.

```bash
npm ci
npm run dev
```

## التحقق

```bash
npm test
```

## البناء

```bash
npm run build
```

المشروع مبني باستخدام React وTypeScript وVinext، ومهيأ حاليًا للنشر عبر ChatGPT Sites، مع قابلية التغليف لاحقًا لأندرويد وويندوز.
